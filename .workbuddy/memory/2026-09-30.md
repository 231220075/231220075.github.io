## 博客从 Hexo 迁移为自建零依赖静态站点

**背景**：`~/Desktop/code/blog` 原为 Hexo + Butterfly 主题站点，本地 `node_modules/.bin/hexo`
已损坏（SIGTERM 退出），发布链路断裂；且 `source/CNAME` 与页面硬编码的
`summer-flower.com` 已易主（现指向他人 WordPress 站点），导致社交卡片与部分绝对链接全错。

**决策**（经用户确认）：
1. 放弃自定义域名，固定使用 `https://231220075.github.io`
2. 重新设计轻量自研主题，视觉不沿用 Butterfly
3. 同时提供 GitHub Actions 云端自动构建 + 本地 `./blog publish` 一键脚本

**新架构**：
```
blog/             CLI 入口（new/dev/build/publish/status/clean/setup/rm）
site.config.mjs   站点配置（标题、导航、社交、功能开关、giscus）
content/posts/    文章 md（15 篇）
content/pages/    固定页面 md（about/links/music/movies/games/browser/photos-gallery/sitemap/archives）
assets/{css,js,img,photos,photos-gallery}
static/           原样拷贝（manifest.json、upload/）
tools/{markdown,build,server}.mjs
.github/workflows/deploy.yml
public/           构建产物（gitignore）
```

**关键技术点**：
- 生成器零 npm 依赖，仅用 Node 原生模块。`node tools/build.mjs`
- `tools/markdown.mjs` 自写 Markdown 渲染：增量 HTML 扫描器（`createHtmlScanner`）
  按标签深度消费 HTML 块，能正确处理跨行标签、跨行注释、script/style 中的原始内容。
  **不要改回"整段 join 后扫描深度"的写法**，那样遇到未闭合 `<script>` 会提前结束块。
- 文章 URL 保持 `/年/月/日/文件名/`，目录名写原生中文，href 用 `link()` 编码
- 构建前清理 `public/` 用 `unlinkSync` + `rmdirSync` 手动递归，
  **不要用 `fs.rmSync`**：本机有 safe-delete shim，会尝试移到回收站并超时失败
- 图片灯箱、搜索、TOC、暗色模式、阅读进度、代码复制均在 `assets/js/main.js`，无 CDN 依赖
- Giscus 由 main.js 动态注入（为了跟随主题色），HTML 里只留 `[data-giscus]` 占位

**Hexo 遗留**：全部移至 `.hexo-backup/hexo/`（已 gitignore），包括 node_modules、
source/、themes/、_config*.yml、.deploy_git、旧 public（存为 `.hexo-backup/public 3`）。
旧站 `favicon.ico` 已从 `.deploy_git/img/` 恢复到 `assets/img/`。
